the funniest sick-day excuse, sent as a text to the boss.

Bounty: https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36

## How it works

`main.py` (pure Python standard library, no dependencies) writes the excuse
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). The output is fully
deterministic: the same bytes on every run.

Run it:

```sh
python3 main.py
```
